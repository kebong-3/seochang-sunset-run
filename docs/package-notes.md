# 서구 선셋런 제출 패키지 구성과 확인 범위

**광주광역시 서구청 기획실 정의형 제작**  
문서 기준일: 2026년 11월 1일

## 패키지의 기준

원본은 [kebong-3/seochang-sunset-run](https://github.com/kebong-3/seochang-sunset-run) 저장소의 다음 커밋입니다.

`4192bf908b655cda6918f28422c8c2c0f954ffa7`

현재 `index.html`이 사용하는 **11번 WebGL 빌드와 웹 기능을 보존**하고, 참조하지 않는 과거 빌드를 제외한 뒤 소개·실행·제출 문서를 추가하는 구성입니다. 아래 파일 수와 용량은 문서·이미지·로컬 실행 도구를 추가하기 전의 게임 파일 기준입니다.

| 구분 | 파일 수 | 파일 크기 합계 |
| --- | ---: | ---: |
| 원본 저장소 게임 파일 | 32개 | 118,549,008바이트 |
| 미참조 과거 빌드 제외 후 | 16개 | 25,310,478바이트 |
| 제외한 파일 | 16개 | 93,238,530바이트 |

이 값은 ZIP 압축 후 크기나 최종 제출 패키지의 전체 크기가 아닙니다. 문서·사진·실행 도구를 포함하면 최종 파일 수와 크기는 늘어납니다.

## 유지한 부분과 정리한 부분

- **유지:** `Build/11.*` 실행 파일, `index.html`, `TemplateData/`, `Community/`, `Quality/`, 기록판과 배포 설정.
- **제외:** 현재 진입점이 참조하지 않는 `Build/5.*`, `Build/7.*`, `Build/9.*`, `Build/10.*`의 각 4개 파일, 총 16개.
- **추가 정리:** README, 구동안내·AI 개발 기록·실제 촬영 대본·등록 안내, 화면 자료와 Python 기반 로컬 실행 도구.

11번 게임 바이너리는 원본과 동일하게 유지했습니다. 정리 과정에서 새 게임 기능을 구현하거나 게임 내부 로직·점수·정책카드 내용을 바꾼 것으로 설명하지 않습니다.

## 파일 수준에서 확인한 내용

원본과의 해시 대조, 사용 빌드의 gzip 압축 데이터 검사, HTTP 제공 시 응답 확인을 수행한 범위입니다. 이러한 확인은 파일 보존·압축 무결성·전송 상태에 대한 근거이며, 게임을 직접 끝까지 플레이한 결과와는 구분합니다.

**전체 코스 완주, 게임 내부의 모든 선택·결과 화면, 기기별 성능, 운영 기록 서버의 정상 동작은 이번 패키지 점검에서 최종 검증한 상태가 아닙니다.** 실제 플레이 녹화본도 현재 패키지의 완성 산출물로 포함하지 않습니다. 촬영 계획은 [실제 플레이 촬영용 대본](demo-recording-script.md)에 정리되어 있습니다.

## 실행과 독립 운영의 범위

게임은 WebGL 2·WebAssembly를 지원하는 브라우저에서 실행합니다. 내려받은 패키지는 Python 3.9 이상에서 `START_WINDOWS.bat` 또는 `python tools/serve.py --open`으로 실행하며, Python 표준 라이브러리만 사용해 별도의 npm·pip 설치가 필요하지 않습니다.

기본 접속 주소는 `http://127.0.0.1:8000/`이며 `--port 8001` 등으로 포트를 바꿀 수 있습니다. 전체 절차는 [구동안내서](quickstart.md)를 따릅니다.

온라인 기록 기능은 별도 운영 중인 Supabase 서버를 사용합니다. **Unity 프로젝트 원본과 기록 서버·DB 구성 원본은 이 패키지에 포함되어 있지 않습니다.** Unity 게임 재빌드나 다른 기관의 독립 운영에는 원본과 운영 설정을 별도로 확보해야 합니다.

## 제출 자료의 의미

- `README.md`는 접속 주소·목적·기능·실행 방법을 안내합니다.
- `docs/quickstart.md`는 실제 실행 절차의 기준 문서입니다.
- `docs/ai-development.md`는 담당자와 AI의 역할, 확인된 개발 범위를 설명합니다.
- `docs/demo-recording-script.md`는 실제 플레이 촬영을 위한 계획이며 녹화 완료 증거가 아닙니다.
- `docs/public-gitlab-upload.md`는 폴더 구조를 유지해 공공 GitLab에 등록하는 방법을 안내합니다.
- `docs/media/`는 기존 제작가이드에 수록된 게임 화면 자료입니다.

AI는 기획·코딩·수정 등 개발 지원에 활용했으며, 현재 게임에 실시간 AI 추론 기능을 추가한 패키지가 아닙니다. 이용 증가·정책 이해·예산 또는 시간 절감 등의 실측 성과를 새로 기재하지 않았습니다.
