# 서구 선셋런 AI 활용과 직접개발 과정

**광주광역시 서구청 기획실 정의형 제작**  
문서 기준일: 2026년 11월 1일

## 개발 목적과 AI 활용 범위

서구 선셋런은 서창억새노을마라톤을 소재로 행사와 정책 정보를 게임 안에서 접하도록 만든 시범 웹게임입니다. 담당자가 행사 목적과 전달할 내용을 정하고, AI의 도움으로 기획을 정리하고 코드를 작성·수정하며 웹에서 실행할 수 있는 결과물로 발전시켰습니다.

**현재 AI 활용 범위는 개발 과정의 기획·코딩·오류 검토·반복 수정 지원입니다.** 배포된 게임은 Unity WebGL과 JavaScript로 실행하며, 실시간 AI 추론이나 이용자별 AI 콘텐츠 생성 기능은 탑재하지 않았습니다.

## 담당자와 AI의 역할

| 개발 단계 | 담당자가 수행한 역할 | AI가 지원한 역할 | 연결된 결과물 |
| --- | --- | --- | --- |
| 행사와 목표 설정 | 행사 소재, 참여 대상, 알릴 내용을 정함 | 요구사항을 작은 게임의 흐름으로 정리 | 행사 안내와 러닝게임 구성 |
| 첫 버전 구현 | 구현할 범위를 정하고 프로젝트에 적용 | 코드 작성과 적용 순서 안내 | Unity 게임과 웹 시작 화면 |
| 실행과 개선 | 직접 실행하고 불편한 화면·오류를 전달 | 원인 검토, 수정 방향과 코드 제안 | 카메라·주행 화면·그래픽·조작 경험 개선 |
| 기록과 공유 구성 | 닉네임·기록·완주 공유 등 필요한 경험을 결정 | 웹 기능과 기록 연결 코드 구현 지원 | 온라인 기록판과 완주 이미지 기능 |
| 확인과 배포 | 화면·내용을 확인하고 웹 빌드·공유 진행 | 실행·배포 절차와 설명 문서 작성 지원 | 웹 실행 파일, 접속 주소, 제작가이드 |

개발자료에 기록된 작업 방식은 **행사 정하기 → 작은 첫 버전 요청 → Unity에서 실행 → 화면·오류를 바탕으로 수정 → 웹 빌드와 공유**입니다. 담당자가 목적과 내용, 개선 방향을 결정하고 결과를 확인하는 역할을 계속 맡았습니다.

## 반복 개선으로 연결한 기능

기존 제작 문서에는 모바일에서 앞길이 보이도록 카메라를 조정하고, 화면을 복잡하게 만드는 주자 배치와 달리기 표현을 고친 과정이 기록되어 있습니다. 억새·노을·하늘의 화면 표현, 완주 이미지 저장·공유, 실제 게임 참여자 기록판도 개선 항목으로 정리되어 있습니다.

현재 저장소에서는 시작 화면·닉네임·기록 공개 선택, 화질 설정, 기록 API 연결, 코스별 기록판, 기기 내 완주 이미지 생성 등의 웹 코드를 확인할 수 있습니다. 게임 안내에는 정책카드 수집과 O/X 레인 선택이 포함되어 있습니다. 개발 문서의 개선 이력과 현재 웹 코드의 구현 범위를 함께 설명합니다.

## 실제 결과와 예시의 구분

- **게임 기록:** 화면의 시간·거리는 게임에서 환산한 값입니다. 게임 속 가상 선수 1,500명과 실제 웹게임 참여자의 온라인 순위는 별도입니다.
- **예시 기록:** 기록판의 `?demo=1`은 예시 데이터를 보여주는 화면이며 실제 이용 실적에 포함하지 않습니다.
- **요청문 예시:** 제작가이드의 ‘빈칸을 채워 첫 게임을 요청하는 문장’은 제작 방법을 설명하는 예시입니다. 실제 개발 대화 전체나 특정 AI 모델의 수행 기록을 대신하지 않습니다.
- **확인한 성과 범위:** 웹 실행본과 관련 기능·문서를 만들었다는 개발 결과를 설명합니다. 정책 인지도, 이용 증가, 비용·시간 절감은 아직 실측 성과로 제시하지 않습니다.

## 다른 행사와 기관에 적용하는 조건

담당자가 공식 행사·정책 자료를 정하고, 작은 기능부터 구현해 실행·수정하는 개발 방식은 다른 업무에서도 참고할 수 있습니다. 다른 지역의 게임으로 적용하려면 해당 지역 자료를 검토해 웹 안내와 게임 내부의 카드·퀴즈·화면을 함께 수정해야 합니다. 행사명만 바꾸면 전체 콘텐츠가 자동 전환되는 기능은 현재 제공하지 않습니다.

웹 화면은 해당 파일에서 수정할 수 있지만 게임 내부를 바꾸려면 **Unity 프로젝트 원본과 재빌드**가 필요합니다. 현재 저장소에는 Unity 원본 및 기록 서버·DB 구성 원본이 포함되어 있지 않으므로, 독립 운영이나 타 기관 이관 시 원본·운영 설정·사용 에셋의 이용 범위를 함께 확보해야 합니다.
