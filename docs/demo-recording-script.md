# 서구 선셋런 실제 플레이 시연 촬영 대본

제작: 광주광역시 서구청 기획실 정의형  
구성: 13장면, 목표 길이 4분 15초  
상태: 실제 플레이 촬영용 구성안. 실제 조작과 녹화 결과에 맞춰 장면·내레이션을 확정한다.  
출품 분야: 세션 1 AI 정부 실험실 챔피언십 자유주제

## 제작 원칙

- 실제 배포 화면을 중심으로 구성한다. 기능을 설명하는 합성 화면을 실제 작동 화면처럼 사용하지 않는다.
- 시연용 닉네임을 사용하고 기록 공개 선택을 해제한다. 이는 이번 촬영 방식이며, 별도 기능명인 ‘비공개 시연 모드’가 있는 것처럼 표현하지 않는다.
- 전체 게임을 그대로 보여주기 어려우면 주행 구간을 편집한다. 해당 구간에 ‘주행 구간 일부 편집’이라고 표시한다. 점수나 완주 결과를 만들어 넣지 않는다.
- 조작법은 실제 화면에서 확인한 입력 방식으로만 안내한다. 키보드·모바일 조작을 확인하기 전에는 특정 방향키나 스와이프 동작을 대본에 추가하지 않는다.
- 모델명, 실시간 AI 생성, 실제 운동거리, 실제 참가자 수, 정책 인지도 개선 수치 등은 확인되지 않은 상태에서 넣지 않는다.
- 5km·10km는 게임 코스 표기다. 게임 속 가상선수 1,500명과 실제 게임 이용자 기록을 구분한다.
- 내레이션은 차분하고 밝은 설명 말투로 읽는다. 장면별로 문장 끝에 짧은 여유를 두고 화면 조작을 보여준다.

## 장면별 대본

### 장면 1 제목과 개발 목적

시간: 00:00–00:18

화면: 선셋런 시작 화면을 배경으로 제목을 띄운다. 하단에 제작자 표기를 넣는다. 첫 3초 안에 게임 이름과 실제 플레이 모습이 보이게 한다.

화면 자막:

- 서구 선셋런
- 정책과 행사 안내를 게임으로 체험하는 웹 프로토타입

### 장면 2 접속과 시작 화면

시간: 00:18–00:38

화면: 실제 배포 주소로 접속한다. 로딩을 짧게 보여준 뒤 시작 화면의 행사·장소·코스 안내를 천천히 훑는다. 실제 주소를 화면 하단에 표시한다. 모바일 화면은 실제 정상 실행 확인 후에만 삽입한다.

화면 자막:

- 누리집 접속 → 시작 화면 확인
- 실제 배포 주소 표시

내레이션:

> 사용자는 안내된 주소로 접속해 시작 화면을 만납니다. 별도 프로그램을 설치하는 절차 없이 브라우저에서 체험하도록 구성했습니다. 시작 화면에서는 행사와 코스 안내를 확인하고, 게임에 참여할 준비를 합니다.

### 장면 3 닉네임과 기록 공개 선택

시간: 00:38–00:56

화면: 시연용 닉네임을 입력한다. 기록 공개 선택이 해제된 상태를 보여준다. 실제 사람의 이름·이메일 등을 입력하지 않는다. 닉네임을 입력한 상태에서 게임 시작 전 화면을 잠시 유지한다.

화면 자막:

- 시연용 닉네임 입력
- 이번 시연은 기록 공개 해제

내레이션:

> 시작 화면에서 게임에 사용할 닉네임을 입력합니다. 기록을 공개할지 선택하는 항목도 함께 확인할 수 있습니다. 영상에는 시연용 닉네임을 사용하며, 기록 공개를 해제한 화면으로 입력 방법을 안내합니다.

### 장면 4 코스 선택과 거리의 의미

시간: 00:56–01:16

화면: 5km·10km 안내를 보여준다. 코스를 선택하는 실제 UI가 확인되면 짧은 코스를 선택한다. 별도 선택 UI가 없다면 안내 화면만 보여주고 ‘코스를 선택합니다’라는 설명을 추가하지 않는다.

화면 자막:

- 5km · 10km 게임 코스
- 거리는 게임 안의 코스 표기입니다

내레이션:

> 선셋런에는 오 킬로미터와 십 킬로미터 코스 안내가 있습니다. 여기서 거리는 게임 안에서 달리는 코스를 뜻합니다. 실제 운동거리나 건강관리 실적으로 계산하는 기능은 아니며, 영상에서는 게임의 핵심 흐름을 중심으로 소개합니다.

### 장면 5 게임 시작과 조작

시간: 01:16–01:36

화면: 실제 게임을 시작한다. 캐릭터와 주행 화면을 넓게 보여주고, 실제 작동하는 좌우 레인 이동을 한 번씩 시연한다. 입력 방식 자막은 촬영 담당자가 확인한 조작법으로 교체한다.

화면 자막:

- 해온이와 함께 주행 시작
- 화면 안내에 따라 레인 이동

내레이션:

> 게임을 시작하면 해온이와 함께 코스를 달립니다. 화면의 조작 안내를 따라 레인을 바꾸며 진행합니다. 기본 흐름은 주행하면서 화면의 안내를 확인하고, 레인 이동을 통해 게임에 나타나는 선택에 참여하는 방식입니다.

### 장면 6 정책카드 수집

시간: 01:36–01:55

화면: 정책카드를 실제로 획득하는 순간을 보여준다. 화면에 정책 내용이 표시되면 읽을 수 있도록 해당 부분을 확대하고 3~4초 유지한다. 실제 상세 설명 화면이 없다면 설명창을 합성하지 않는다.

화면 자막:

- 달리며 만나는 정책카드
- 실제 게임에 수록된 내용 표시

내레이션:

> 주행 중에는 정책카드를 모으는 요소가 등장합니다. 게임의 목표를 따라가면서 정책 정보를 만나도록 연결한 부분입니다. 카드 수집을 플레이 안에 넣어, 달리는 동안 정책과 관련된 내용을 접하게 하려는 구성입니다.

### 장면 7 O/X 질문에 참여

시간: 01:55–02:14

화면: 실제 O/X 질문이 보이는 구간을 사용한다. 질문 내용을 읽을 시간을 준 뒤 왼쪽 O 또는 오른쪽 X 레인으로 이동한다. 정답 여부와 효과는 화면에 실제 표시되는 만큼만 보여준다.

화면 자막:

- O는 왼쪽 · X는 오른쪽
- 질문 확인 → 레인 선택

내레이션:

> 오엑스 질문에서는 내용을 확인한 뒤 답에 맞는 레인으로 이동합니다. 오라고 생각하면 왼쪽, 엑스라고 생각하면 오른쪽입니다. 질문을 읽고 직접 선택하는 과정을 주행과 이어, 정책을 접하는 방식에 참여 동작을 더했습니다.

### 장면 8 주행 기록과 가상선수 구분

시간: 02:14–02:33

화면: 실제 주행과 순위 표시를 보여준다. 1,500명 표기가 나타나는 경우 해당 숫자 근처에 ‘게임 속 가상선수’ 자막을 넣는다. 실제 게임참여자 기록 화면이 별도로 검증되면 두 기록의 차이를 짧게 보여준다.

화면 자막:

- 게임 속 가상선수와의 순위
- 가상선수 1,500명 ≠ 실제 이용자 1,500명
- 주행 구간 일부 편집 (해당하는 경우)

내레이션:

> 주행 과정의 순위에는 게임 속 가상선수와의 경쟁이 반영됩니다. 안내에 나오는 천오백 명은 실제 이용객 수가 아닙니다. 실제 게임참여자의 기록과 구분해서 설명하며, 중간 주행 구간은 영상 길이에 맞춰 일부 편집했습니다.

### 장면 9 완주와 결과 확인

시간: 02:33–02:54

화면: 실제 완주 순간부터 결과 화면으로 이어간다. 점수·메달·하트·정책카드 수 가운데 실제 표시된 항목만 확대한다. 결과가 저장되지 않았거나 전송에 실패하면 ‘저장 완료’ 자막을 넣지 않는다.

화면 자막:

- 완주 결과 확인
- 이번 플레이에서 얻은 기록

내레이션:

> 코스를 마치면 이번 플레이의 결과를 확인합니다. 점수와 획득한 정책카드 등 실제 게임 결과가 완주 화면에 담깁니다. 달리기를 끝낸 뒤에도 자신이 어떤 경험을 했는지 돌아볼 수 있도록, 결과 화면을 마무리 단계로 연결했습니다.

### 장면 10 완주 카드 저장과 공유 준비

시간: 02:54–03:12

화면: 실제 완주 PNG 카드 생성·미리보기·저장을 보여준다. 공유 기능은 공개 게시를 하지 않고 공유 준비 화면까지만 시연한다. 해온이의 코디와 기록은 실제 생성된 카드 내용을 그대로 쓴다.

화면 자막:

- 나의 완주 카드
- 이미지 저장 · 공유 준비

내레이션:

> 완주 결과는 해온이와 함께 담긴 이미지 카드로 남길 수 있습니다. 카드의 내용을 확인한 뒤 이미지로 저장하거나 공유를 준비하는 흐름입니다. 영상에서는 실제 생성된 카드와 저장 기능을 소개하며, 공개 게시를 진행하지 않습니다.

### 장면 11 AI 직접개발과 운영 관점

시간: 03:12–03:34

화면: 시작·정책카드·O/X·완주 장면을 짧게 연결한다. 이어 저장소 README 또는 실제 구동안내서의 기능·실행 방법 부분을 보여준다. AI 모델 로고나 모델명은 확인된 개발 기록이 없으면 넣지 않는다.

화면 자막:

- 공무원의 AI 직접개발 실험
- 기획 · 구현 · 수정 과정을 직접 수행
- 기능과 실행 방법을 문서로 정리

내레이션:

> 이 작품은 공무원이 AI의 도움을 받아 기획하고 구현을 다듬어 가는 직접개발 실험입니다. 주민이 정책을 만나는 흐름을 직접 설계하고, 실행 방법과 기능을 문서로 정리합니다. 운영자가 무엇을 확인하고 고쳐야 하는지도 함께 남기려 합니다.

### 장면 12 현재 범위와 확장 조건

시간: 03:34–03:56

화면: 실제 현재 버전 화면을 배경으로 ‘현재 범위’와 ‘확장에 필요한 작업’을 구분해 표시한다. 다른 지역 자동 전환 UI나 아직 구현하지 않은 관리 기능은 보여주지 않는다.

화면 자막:

- 현재: 서구 콘텐츠를 체험하는 프로토타입
- 다른 지역 적용: 콘텐츠와 운영 설정 검토 필요
- 정책 이해·참여 효과: 향후 실제 사용으로 확인

내레이션:

> 현재는 서구 콘텐츠를 체험하는 프로토타입입니다. 다른 지역에 적용하려면 해당 지역의 정책과 행사 정보를 검토하고, 콘텐츠와 운영 설정을 맞추는 작업이 필요합니다. 정책 이해와 참여에 어떤 도움이 되는지는 앞으로 실제 사용을 통해 확인하겠습니다.

### 장면 13 마무리

시간: 03:56–04:15

화면: 정책카드·O/X·완주 카드 장면을 짧게 다시 보여준 뒤 제목 화면으로 마무리한다. 실제 배포 주소와 제작자 표기를 함께 남긴다. 평가 점수·수상 예상·검증되지 않은 효과 수치는 넣지 않는다.

화면 자막:

- 서구 선셋런
- 정책 안내에 참여 경험을 더하는 시도
- 광주광역시 서구청 기획실 정의형
- 실제 배포 주소

내레이션:

> 서구 선셋런은 정책 안내에 게임의 참여 경험을 더하는 시도입니다. 접속하고, 달리고, 질문에 답하고, 완주 기록을 남기는 흐름을 통해 주민과 정책이 만나는 방식을 넓혀 가겠습니다. 지금까지 서구 선셋런 시연이었습니다. 감사합니다.

- 시작 화면에 행사·장소·5km·10km 안내가 있다.
- 닉네임 입력은 2~12자다. 기록 공개 여부를 선택할 수 있다.
- 클릭·터치로 시작하며 키보드 Enter·Space 시작 처리도 코드에 있다. Unity 내부 주행 조작은 실제 플레이 확인이 필요하다.
- 안내문에 정책카드 수집과 ‘O는 왼쪽, X는 오른쪽 레인’ 안내가 있다. 실제 질문과 반응은 촬영으로 확인한다.
- 커뮤니티 코드에는 코스별 실제 게임참여자 최고기록과 게임 속 NPC 1,500명 순위의 구분이 있다. 1,500명을 실이용자로 표현하지 않는다.
- 완주 PNG 카드에는 해온이 코디·메달·점수·하트·정책카드 수 등이 구성된다. 기기 안에서 이미지 생성·사진 공유·저장을 처리하도록 작성되어 있다.
- 웹 코드 확인 범위에서 런타임 LLM·AI API는 확인되지 않았다. ‘AI 맞춤 정책 생성’, ‘실시간 AI 문제 생성’, ‘AI 코치’라고 설명하지 않는다.

### 촬영으로 확정할 항목

1. 배포 주소, 실제 시작 성공 여부, 로딩 시간, 브라우저 호환성.
2. 닉네임과 기록 공개 해제 후의 동작. 서버 공개 기록이 발생하지 않는지 확인.
3. 실제 코스 선택 UI 유무. 없으면 장면 4의 화면도 안내 확인까지만 구성.
4. 해온이의 실제 주행·좌우 조작, O/X 질문의 위치와 반응.
5. 정책카드 획득과 정책 내용 표시 방식. 상세 열람 기능이 없으면 있는 것처럼 설명하지 않음.
6. 완주 결과 화면에 실제 표시되는 항목과 완주 카드 생성·저장 성공.
7. 기록·순위 표시의 실제 문구. 가상선수와 실제 이용자를 자막으로 구분.
8. 개발자의 실제 AI 활용 경위. 확인되지 않으면 장면 11의 ‘AI의 도움을 받아’ 표현은 개발 증빙과 일치하도록 조정.

### 구현과 계획의 구분

- 장면 1의 정책 체험은 개발 목적이다. 정책 인지도·참여율 향상이 입증됐다는 성과 주장이 아니다.
- 장면 11의 실행 방법 정리는 실제 제출 README·구동안내서를 보여줄 때만 완성 표현으로 쓴다. 아직 준비 중이면 해당 문장을 미래형으로 유지한다.
- 장면 12의 다른 지역 적용과 효과 확인은 향후 과제다. 현재 자동 지역 변환이나 효과 측정 기능이 구현됐다고 주장하지 않는다.
- 다른 지자체 확산 실적, 비용 절감액, 실제 이용자 수, 건강 증진 효과, 모델별 테스트 결과는 이 초안에 넣지 않았다.

### 길이 검토

- 표의 편집 목표는 255초로 5분 이내다.
- 최종 음성 생성 후 실제 길이를 확인한다. 255초를 넘으면 말 빠르기를 무리하게 높이기보다 장면 2·5·6·11의 보조 문장을 줄인다.
- 장면 8에서 주행 구간을 편집하지 않았다면 내레이션의 마지막 문장과 편집 자막을 삭제한다.
- 화면 조작이 내레이션보다 늦으면 장면별 2~3초를 조정하되 전체 길이는 4분 30초 안을 우선 목표로 한다.
