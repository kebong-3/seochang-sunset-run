# 서구 선셋런 구동안내

**광주광역시 서구청 기획실 정의형 제작**  
문서 기준일: 2026년 11월 1일

## 바로 접속하기

**[▶ SUNSET RUN 실행](https://sunset-run.vercel.app/)**

해온이와 함께 행사·정책 정보를 접하고, 정책카드와 O/X 퀴즈를 만나며, 완주 결과를 남기는 웹게임입니다. PC·모바일의 최신 브라우저에서 접속합니다. 첫 접속에는 Unity 게임 데이터가 다운로드됩니다.

## 실행 환경

| 항목 | 필요한 환경 |
| --- | --- |
| 웹 체험 | WebGL 2·WebAssembly를 지원하는 최신 브라우저 |
| 내려받은 파일 실행 | Python 3.9 이상, 압축을 푼 전체 프로젝트 폴더 |
| 추가 설치 | Python 표준 라이브러리 사용. npm·pip 패키지 설치 불필요 |
| 온라인 기록판 | 기록 서버에 연결할 수 있는 인터넷 환경 |

## 내려받은 패키지 실행

### Windows에서 시작 파일 이용

1. ZIP의 압축을 풉니다.
2. `README.md`와 `index.html`이 있는 폴더에서 **`START_WINDOWS.bat`**를 실행합니다.
3. 열린 브라우저에서 게임이 로딩될 때까지 기다립니다. 브라우저가 열리지 않으면 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)에 접속합니다.

실행 중인 서버 창은 게임을 이용하는 동안 열어 둡니다. Python을 찾지 못한다는 안내가 나오면 Python 3.9 이상이 설치되어 있는지 확인합니다.

### 명령으로 실행

프로젝트 폴더에서 터미널을 열고 다음 명령을 실행합니다.

```bash
python tools/serve.py --open
```

Windows에서 `python` 명령을 찾지 못하고 Python 실행기 `py`를 사용 중이면 다음 명령을 사용합니다.

```bash
py -3 tools/serve.py --open
```

기본 주소는 **`http://127.0.0.1:8000/`**입니다. 8000번 포트가 이미 사용 중이면 다른 번호로 실행합니다.

```bash
python tools/serve.py --open --port 8001
```

이때 접속 주소는 [http://127.0.0.1:8001/](http://127.0.0.1:8001/)입니다. 종료할 때는 서버 창에서 `Ctrl+C`를 누릅니다. `index.html`을 더블클릭하는 대신 포함된 서버로 폴더 전체를 제공해야 합니다.

## 핵심 이용 흐름

1. **시작 준비** — 닉네임을 입력합니다. 기록 공개 항목은 처음에는 선택된 상태이며, 원하는 경우 선택을 해제할 수 있습니다. 클릭·터치 또는 시작 화면의 `Enter`·`Space`로 진행합니다.
2. **게임 진행** — 5km·10km 코스와 게임 안의 조작 안내를 확인합니다. 정책카드를 모으고 O/X 질문에서는 O는 왼쪽, X는 오른쪽 레인을 선택합니다.
3. **완주 결과** — 게임 환산 기록·점수·모은 카드 수 등 결과를 확인하고 기념 이미지를 저장하거나 공유합니다.
4. **온라인 기록 확인** — 공개를 선택한 경우 실제 게임 참여자의 코스별 최고기록과 내 기록을 확인합니다. 기록판에서 자신의 기록을 삭제할 수 있습니다.

게임 속 가상 선수 1,500명의 순위는 실제 게임 이용자 순위와 별개입니다. 시간·거리는 게임 환산값이며 실제 운동 측정 결과가 아닙니다. 기록판의 `?demo=1`은 예시 데이터를 보여주는 주소입니다.

## 기록과 화면에 관한 안내

완주 이미지는 **이용자 기기 안에서 생성**하며 서버에 자동 업로드하지 않습니다. 온라인 기록 기능은 별도 운영 중인 Supabase 기록 서버에 연결합니다. 참여자 구분에 브라우저 저장 ID를 사용하므로 다른 기기나 사이트 데이터 삭제 후에는 별도 참여자가 될 수 있습니다.

기록 서버에 연결되지 않으면 순위 조회·기록 전송이 제한될 수 있습니다. 로컬 서버 실행은 게임 파일을 제공하는 기능이며 기록 서버를 새로 만드는 절차는 아닙니다.

## 실행이 어려울 때

| 보이는 상태 | 먼저 확인할 내용 |
| --- | --- |
| Python 명령을 찾지 못함 | Python 3.9 이상 설치 여부와 `py -3` 실행 가능 여부 |
| 주소에 접속되지 않음 | 서버 창이 실행 중인지, 접속 주소의 포트가 같은지 확인 |
| 8000번 포트를 사용 중이라는 메시지 | `--port 8001`로 실행하고 8001 주소로 접속 |
| WebGL 지원 안내가 표시됨 | WebGL 2 지원 브라우저·기기에서 실행, 브라우저 그래픽 설정 확인 |
| 게임 파일을 찾지 못함 | `index.html`과 `Build/`, `Community/`, `Quality/`, `TemplateData/`를 함께 압축 해제했는지 확인 |
| 화면이 무겁거나 느림 | 게임의 화질 설정을 낮추고 다른 브라우저·기기 환경 확인 |
| 기록판이 표시되지 않음 | 인터넷 연결과 별도 기록 서버의 운영 상태 확인 |

## 제공 범위

패키지는 WebGL 실행본과 웹 소스·문서를 제공합니다. 게임 내부를 수정·재빌드하는 Unity 프로젝트 원본, 기록 서버·DB 구성 원본은 포함되어 있지 않습니다. 전체 코스 완주와 기기별 동작을 최종 확인할 때는 [실제 플레이 촬영용 대본](demo-recording-script.md)을 참고할 수 있습니다.
